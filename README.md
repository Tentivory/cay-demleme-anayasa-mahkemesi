# ÇAY DEMLEME ANAYASA MAHKEMESİ

## Kurumsal Kimlik

Bu yazılım, çayın demlenme süresine ilişkin anayasal uyuşmazlıkları kesin olarak çözen üst yargı merciidir.

Kararlar **nihaidir**. İstinaf yoktur. Temyiz yoktur. Şeker koyup koymama meselesi içtihatla kapatılmıştır.

> "Dem, zamandır. Zaman, usuldür. Usul, esastır."  
> — *Genel Kurul, 9 Eylül 2026, üçüncü oturum, çay soğumadan*

## Yasal Dayanak

- Çay Kanunu m. 1 (hayalî)
- Demleme Usul Yönetmeliği (henüz yazılmamış, yine de uygulanır)
- İçtihat: Bardak kırılırsa duruşma ertelenir
- İçtihat: Poşet çay, ihtiyati tedbir kapsamındadır

## Kurulum

```bash
python3 mahkeme.py
```

Bağımlılık yoktur. Anayasa kendi kendini yürütür.

## Kullanım

Program size dem süresini sorar. Siz bir sayı söylersiniz. Mahkeme:

1. Usul incelemesi yapar
2. Esasa girer (isteksizce)
3. Gerekçeli karar yazar
4. Kararı tebliğ eder
5. Çayınız soğur

## Karar Örnekleri

| Dem (dk) | Hüküm |
|---|---|
| 0-1 | RET — çay değil, ılık su suçlaması |
| 2-4 | KABUL — anayasal denge |
| 5-8 | İHTİYATİ TEDBİR — acılık riski |
| 9+ | İPTAL — tanen darbesi |
